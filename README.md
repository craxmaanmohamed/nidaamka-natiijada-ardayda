# Nidaamka Natiijada Ardayda

Mashruucan waxaa loo diyaariyey Vite + React + TypeScript + Tailwind CSS si loogu deploy-gareeyo Vercel.

## Ku socodsii kombiyuutarka

1. Ku rakib Node.js LTS.
2. Fur folder-kan terminal/VS Code.
3. Orod `npm install`.
4. Orod `npm run dev`.

## GitHub

Upload dhammaan waxa ku jira ZIP-kan (ha upload-gareyn ZIP-ka oo keliya). Qaab-dhismeedka:
- `index.html`
- `package.json`
- `src/App.tsx`
- `src/main.tsx`
- `src/index.css`
- `vite.config.ts`
- `tailwind.config.js`
- `postcss.config.js`
- `tsconfig.json`

## Vercel

Import repository-ga GitHub. Vercel badanaa si toos ah ayuu u aqoonsanayaa Vite.
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: `./`

## Fiiro amni

Ka hor inta aan lagu isticmaalin xog arday oo dhab ah, hubi Supabase Row Level Security (RLS), siyaasadaha gelitaanka, iyo habka xaqiijinta. Koodhka browser-ka ku jira ma qarin karo siraha. Ha ku darin service-role key ama sir gaar ah frontend-ka.
